# VOXERA v1.0.0-RC1 Release Notes

**Release date:** 2026-07-11  
**Codename:** Enterprise Foundation  
**Type:** Release Candidate

---

## Overview

VOXERA v1.0.0-RC1 is the first release candidate of the enterprise voice agent platform. This release certifies the platform for **design partner onboarding** and **controlled production pilots** — not general availability.

---

## What's Included

### Enterprise Platform

- Multi-tenant REST API with IAM (JWT, API keys, RBAC, organizations)
- Enterprise Dashboard (agents, knowledge, workflows, tools, tenants, users, audit, integrations)
- Enterprise Integration Platform (49 providers, OAuth, webhooks, sync engine, field mapping)

### AI Cognitive Stack

- Planner Agent — intent classification, reasoning, policy engine
- Verifier Agent — hallucination detection, compliance, risk assessment
- Workflow Engine — rules, approvals, escalation, routing
- Tool Registry — builtin and webhook tools with circuit breakers
- Knowledge Platform — ingestion pipeline, embeddings, vector stores
- Memory System — working memory, summarization, compression
- RAG — enterprise retrieval with validation

### Voice Infrastructure

- Streaming STT → LLM → TTS pipeline
- WebSocket voice sessions with barge-in
- Twilio telephony integration
- Bounded audio queues with metrics

### Operations

- Docker, Compose, Kubernetes Helm chart
- GitHub Actions CI/CD
- Prometheus metrics, Grafana/Jaeger scaffolding
- 10 database migrations
- Operations runbooks and incident response guides

### Quality

- 261 automated tests
- Golden dataset evaluation (7 domains)
- Voice simulation framework
- Security, chaos, and benchmark test suites

## Known Limitations

See [known-issues.md](known-issues.md). Key items:

- Per-route RBAC not on all tenant APIs (middleware tenant validation only)
- Twilio path may use mock STT without provider configuration
- Coverage gate at 65% (GA target 90%)
- No application-level distributed tracing
- Billing and Live Calls operations WebSocket not fully wired
